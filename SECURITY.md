# Security

Do not include private vault contents, file names, or folder names in public reports.

For a suspected vulnerability, contact `security@bloommd.app` with the plugin version, Obsidian version, operating system, and reproduction steps using synthetic notes. Do not open a public issue until the report has been triaged.

The plugin has no telemetry and no network-based note synchronization. External URLs and the BloomMD desktop protocol are opened only after an explicit user action.
